## 1. MIDI bridge — IN PROGRESS (approved "proceed first")

Play Synth/Keys with no rack keyboard:
- **Musical typing** (primary, zero extra hardware): web tab captures the
  COMPUTER keyboard, GarageBand-style layout (A=C W=C# S=D ... ; Z/X octave),
  keydown/keyup → note on/off, plus clickable on-screen keys.
- **WebMIDI device capture** (Chrome): forward a USB MIDI keyboard's
  noteon/noteoff the same way.
- Transport: WebSocket on the shared httpd if CONFIG_HTTPD_WS_SUPPORT works
  on IDF 4.3, else per-event POST /midi/on|off.
- Module side: a core "soft MIDI" state (held-note stack, last-note priority,
  gate) that Synth + Keys OPT INTO next to their CV1/TR1 reads — exact pitch,
  no CV quantization detour. Velocity accepted, unused in v1.
- Remote verification: send note 69 → bounce → Goertzel expects 440.0 Hz.
- **Hardware-MIDI notes (Arlo asked 07-17):** USB = NO (CP2102 serial bridge,
  classic ESP32 has no USB controller; the port also reboots the module).
  CV input = NO (2 kHz ADC can't recover 31.25 kbaud). **TRIG input = MAYBE:**
  route a hardware UART RX to GPIO36 (TR2) via the GPIO matrix @31250 baud
  with RXD inversion — if the SS8050 trigger conditioning passes 31 kHz
  edges, TR2 becomes a real TRS-MIDI in, feeding the same soft-MIDI stack.
  Bench experiment after the web bridge lands.
  **CV-instead-of-TRIG (Arlo asked): impossible** — CV jacks never reach an
  ESP32 pin; they feed the MCP3208 external ADC over SPI (2 kHz). TRIG jacks
  are the ONLY UART-routable pins. TR2's shared button is fine: normally-open,
  it only garbles frames while pressed (parser resyncs); TR2-as-MIDI would be
  an explicit mode setting anyway.

## 2. FX pack — delay + more (approved: "appealing")

- **util/delay**: the missing effect (upstream had one; machines dropped it).
  Clock-synced times (BPM is everywhere), feedback, mix. Host in Tape, Drums,
  Synth, Keys chains like reverb.
  **DONE 2026-07-17 (delay-fx, NOT yet ear-verified beyond Keys):**
  `components/util/fxdelay.{h,c}` — stereo feedback delay, ~690 KB lazy PSRAM
  slab (2 s max), damping one-pole ("Tone"), equal-power wet/dry, ping-pong,
  NaN guard, cost_us meter. Named `fxdelay` (sampler2 has a legacy `delay_t`).
  Both time modes: `_set_time_ms` (free) + `_set_time_beats(beats,bpm)`
  (clock-synced). Hosted delay->reverb in Keys, Synth, Drums (master insert,
  post-reverb; kept live in the early-return guard), Tape (CLOCK-SYNCED:
  Dly Div 1/16..1/2, tracks `clockin_beat_bpm`/manual). Setup rows + preset/
  autosave + web Remote form on all four. Keys delay confirmed audible by ear
  07-17; Synth/Drums/Tape pending ear-test. Shipped via USB serial flash (WiFi
  was down); OTA layout intact. NO version bump / bin archive yet.
- **Overdrive** (proper, beyond the drums soft-clip: tone/asymmetry),
  **tremolo** (LFO amp, clock-syncable), **flanger** (short mod delay +
  feedback). Shared util pattern like svf/reverb.
  **DONE 2026-07-17 (fx-pack, flashed via OTA, NOT ear-verified):** three
  new util bricks — `util/overdrive.{h,c}` (tanh shaper, drive/tone/bias/
  level, DC-comp asymmetry, svf tone tilt, no slab), `util/tremolo.{h,c}`
  (sine/tri/sqr LFO amp, stereo antiphase auto-pan, `_set_rate_beats`,
  no slab), `util/flanger.{h,c}` (~1-11ms swept fractional delay + fb,
  equal-power mix, `_set_rate_beats`, lazy PSRAM slab). Hosting overdrive
  -> flanger -> tremolo -> delay -> reverb in Keys, Synth, Tape (Tape's
  flanger/tremolo rates CLOCK-SYNCED via divisions). **Drums DEFERRED**
  per Arlo (see below). Menu rows appended at end of each Setup +
  preset/autosave keys.
- **Drums FX = PER-PAD, not master bus (Arlo, 2026-07-17):** Arlo wants the
  drum FX to be a PAD property, not the master insert the delay currently is.
  This is a real redesign — each pad needs its own effect state, and per-pad
  flanger/delay PSRAM slabs multiply (4 pads x slabs); needs a plan (maybe a
  shared FX-send bus with per-pad send amounts, like the reverb send, rather
  than N full inserts). The master delay already on Drums stays until this
  lands. Do NOT add overdrive/tremolo/flanger to the Drums master bus in the
  meantime (would be throwaway).
