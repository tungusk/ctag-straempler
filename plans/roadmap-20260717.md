## 1. MIDI bridge — IN PROGRESS (approved "proceed first")

Play Synth/Keys with no rack keyboard:
- **Musical typing** (primary, zero extra hardware): web tab captures the
  COMPUTER keyboard, GarageBand-style layout (A=C W=C# S=D ... ; Z/X octave),
  keydown/keyup → note on/off, plus clickable on-screen keys.
- **WebMIDI device capture** (Chrome): forward a USB MIDI keyboard's
  noteon/noteoff the same way.
- Transport: WebSocket on the shared httpd if CONFIG_HTTPD_WS_SUPPORT works
  on IDF 4.3, else per-event POST /midi/on|off.
- Module side: a core "soft MIDI" state (held-note stack, last-note priority,
  gate) that Synth + Keys OPT INTO next to their CV1/TR1 reads — exact pitch,
  no CV quantization detour. Velocity accepted, unused in v1.
- Remote verification: send note 69 → bounce → Goertzel expects 440.0 Hz.
- **Hardware-MIDI notes (Arlo asked 07-17):** USB = NO (CP2102 serial bridge,
  classic ESP32 has no USB controller; the port also reboots the module).
  CV input = NO (2 kHz ADC can't recover 31.25 kbaud). **TRIG input = MAYBE:**
  route a hardware UART RX to GPIO36 (TR2) via the GPIO matrix @31250 baud
  with RXD inversion — if the SS8050 trigger conditioning passes 31 kHz
  edges, TR2 becomes a real TRS-MIDI in, feeding the same soft-MIDI stack.
  Bench experiment after the web bridge lands.

## 2. FX pack — delay + more (approved: "appealing")

- **util/delay**: the missing effect (upstream had one; machines dropped it).
  Clock-synced times (BPM is everywhere), feedback, mix. Host in Tape, Drums,
  Synth, Keys chains like reverb.
- **Overdrive** (proper, beyond the drums soft-clip: tone/asymmetry),
  **tremolo** (LFO amp, clock-syncable), **flanger** (short mod delay +
  feedback). Shared util pattern like svf/reverb.

## 3. Tuner (approved, "especially") + Keys auto-tune

- Tuner machine (or Live overlay): pitch-detect line-in, big cents display —
  tune rack oscillators against the module.
- **Keys tie-in (Arlo)**: Keys should be able to TUNE THE SAMPLE — detect the
  loaded sample's actual pitch and set root/fine-offset so it plays in tune.
  Same detector, offline over the zone buffer. Design when Keys ear-verdict
  lands.
