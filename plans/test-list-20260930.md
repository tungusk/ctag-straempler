# Test list — the 09-29 review fixes (made 2026-09-30)

Everything below was fixed and bench-run on `.85` (`review_bench.py --audio`, 0 fail on
the final build). These are the checks the bench cannot do: things to **hear**, things
that need **hands** on the panel or the card, and a few **web page** clicks (the page was
never clicked through — the Chrome extension was offline all session). Tick them off in
any order; nothing here blocks anything.

Commit per item is in `plans/review-fixes-report-20260930.md`.

## Ears (play it)

- [ ] **Reverse, Sampler and Slicer.** A take you know, forward then reverse. It used to
      be a mirror-fold every ~93 ms. (Sampler proven with a chirp; Slicer same code.)
- [ ] **Drums reverb Send Tap = post** with two pads at different sends: the tail as
      before, no crackle (the send now runs through its own filter copy).
- [ ] **Drums, a pad cut mid-sound** (load another sample on a ringing pad): silence,
      not a ~1.4 kHz buzz.
- [ ] **A DAW-exported one-shot** (WAV with LIST/smpl chunks) in Drums or Keys: ends
      without a click.
- [ ] **Web Apply on a reverb patch** (Synth/Tape/Drums): changing an unrelated value no
      longer cuts the reverb tail.
- [ ] **Deck: pause and resume inside a loop** — resumes where it was, not at the window
      start. **Release a loop right after a window move** — no flash of the other window.
- [ ] **DoubleDecker at PPQ 1** (one pulse per bar): armed starts/stops fire on the bar.

## Hands (panel, card, power)

- [ ] **Tape edits survive leaving.** Norm/Rev/Fade/Cut/Paste a take, switch machine,
      come back: the edited take loads (saved as a new CUT_). A reboot before leaving
      still loses the last edit — on purpose; say if it bites.
- [ ] **Tape Len during a long autosave** (right after punching out 30 s): waits, no crash.
- [ ] **Tape Cut on a long crop with little free RAM:** refuses, row reads `no room`.
- [ ] **Knob settings that never used to save** — set, power-cycle, check: Granular
      position/pitch/level; Drums knob-7 attack/start/loop per pad; Slicer FX box, reverb
      mode + mix, and a Grid/Transient pick on a sample that has an `.OT`.
- [ ] **Settings made while on Deck/DoubleDecker** survive a switch and a power cycle
      (the autosave read used to fail under the decks).
- [ ] **Keys FX page during a web Apply** that sets that slot to Off, then turn the
      encoder: no crash, rows rebuild.
- [ ] **Pull the SD card while Deck plays:** the web page stays reachable.
- [ ] **Sampler: arm a voice, switch machine, come back:** not armed, a gate plays.
- [ ] **Looper: bounce, and hit TR1 during it:** the bounce lands, no crash.
- [ ] **Settings > SSID/Password/Api Key text entry** on a card whose CONFIG.JSN was
      hand-edited: edits the right key.
- [ ] **Upload a file while Tracker is active, then switch away:** it converts within
      a second or two of leaving Tracker.

- [ ] **Machine switch from the web page:** the screen repaints once, not twice.
