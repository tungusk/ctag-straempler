## Build/hardware notes learned this session
- GCC **`-Werror=misleading-indentation`** fires on same-line `if(a)x; if(b)y;`
  clamp pairs → use `clampf`/`clampi` helpers or put them on separate lines.
- Adding the 16th machine **filled the `menu.c` selector arrays** — bumped `[16]`→
  `[17]` and the two loops `<16`→`<17`. The next machine needs the same check.
- A new component needs a build **reconfigure** (CMake globs sources).
- clangd LSP is noisy on this project (`-mlongcalls` / `struct DIR redefinition`
  false errors) — the **GCC build is the only arbiter**; ignore the IDE squiggles.
- OTA is the flash path; **verify the device answers `/ota/state` before `ota.sh`**
  (it goes offline intermittently). Rollback protects a bad image at boot.
