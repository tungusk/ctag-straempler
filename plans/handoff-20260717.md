## Lessons added this day
- **Internal RAM is TIGHT** (bc_srv grew ~8 KB for shine): ANY ≥16 KB internal
  alloc or big task stack must be CHECKED + laddered/fail-soft — an unchecked
  task stack broke a distant machine (tracker) weeks later. PSRAM single
  allocs >2.1 MB refused → 1 MiB bank lists (tape).
- **`version.txt` must avoid BOTH `#` AND `;`** (CMake parse errors).
- `/files` lists ONLY ids with a `.JSN` sidecar.
- Blind remote menu-driving: curl `/remote/event`s DROP on this WiFi —
  checkpoint with `/screenshot` before destructive presses.
- Shadow FB is lazy now → the FIRST `/screenshot` after any boot returns 503
  "warming"; retry (the web SCREEN card's auto-refresh handles it).
